Alliteration Marker

Paste a poem, break it into syllables, tag each syllable's sound and stress, and see the alliterative pattern rendered back onto the original text with colored boxes.

Sound chart

1 · Paste the poem

Separate stanzas with a blank line, exactly as in the source text.

2 · Check the syllables, sounds, and stress

Each syllable got an automatic guess for its sound and stress — poetry defeats any algorithm, so check them. Click a syllable's text to fix a split. Use the dropdown to set the onset sound (the sound the syllable starts with). Click the circle to toggle stressed (filled) / unstressed (empty) — for one-syllable words, set this by the poem's meter. The small second dropdown is optional: set it only if a stressed syllable ends in a sound worth checking against the poem's onsets (step 3 of the method).

3 · Marked-up poem

Solid box = the sound falls on a stressed syllable. Dashed box = unstressed. Box color follows the chart above.

Automatic syllable splitting and sound-guessing are approximate — treat every chip as a draft to correct, not a verdict.
